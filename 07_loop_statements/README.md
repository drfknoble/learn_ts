# Loop Statements

This tutorial will introduce repetition with loops and iteration.

The lesson deck is [07_loop_statements.md](07_loop_statements.md), and its examples are in [07_loop_statements.ts](07_loop_statements.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/07_loop_statements/07_loop_statements.ts && node learn_ts/07_loop_statements/07_loop_statements.js
```

The Marp deck is exported to [07_loop_statements.html](07_loop_statements.html).
