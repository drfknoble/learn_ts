# Interfaces and Type Aliases

This tutorial will introduce naming object shapes with `interface` and `type`.

The lesson deck is [10_interfaces_types.md](10_interfaces_types.md), and its examples are in [10_interfaces_types.ts](10_interfaces_types.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/10_interfaces_types/10_interfaces_types.ts && node learn_ts/10_interfaces_types/10_interfaces_types.js
```

The Marp deck is exported to [10_interfaces_types.html](10_interfaces_types.html).
