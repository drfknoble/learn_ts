# String Objects

This tutorial will introduce text values, string operations, and regular expressions.

The lesson deck is [09_string_objects.md](09_string_objects.md), and its examples are in [09_string_objects.ts](09_string_objects.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/09_string_objects/09_string_objects.ts && node learn_ts/09_string_objects/09_string_objects.js
```

The Marp deck is exported to [09_string_objects.html](09_string_objects.html).
