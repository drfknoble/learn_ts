# Hello World

This tutorial will introduce a first TypeScript program and terminal output.

The lesson deck is [02_hello_world.md](02_hello_world.md), and its examples are in [02_hello_world.ts](02_hello_world.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/02_hello_world/02_hello_world.ts && node learn_ts/02_hello_world/02_hello_world.js
```

The Marp deck is exported to [02_hello_world.html](02_hello_world.html).
