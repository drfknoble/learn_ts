# Enums

This tutorial will introduce numeric enums, string enums, `const enum`, and when to prefer literal unions instead.

The lesson deck is [14_enums.md](14_enums.md), and its examples are in [14_enums.ts](14_enums.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/14_enums/14_enums.ts && node learn_ts/14_enums/14_enums.js
```

The Marp deck is exported to [14_enums.html](14_enums.html).
