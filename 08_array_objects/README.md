# Arrays and Objects

This tutorial will introduce collections of values and structured data.

The lesson deck is [08_array_objects.md](08_array_objects.md), and its examples are in [08_array_objects.ts](08_array_objects.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/08_array_objects/08_array_objects.ts && node learn_ts/08_array_objects/08_array_objects.js
```

The Marp deck is exported to [08_array_objects.html](08_array_objects.html).
