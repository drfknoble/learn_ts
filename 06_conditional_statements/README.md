# Conditional Statements

This tutorial will introduce decisions, comparisons, and guarded behavior.

The lesson deck is [06_conditional_statements.md](06_conditional_statements.md), and its examples are in [06_conditional_statements.ts](06_conditional_statements.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/06_conditional_statements/06_conditional_statements.ts && node learn_ts/06_conditional_statements/06_conditional_statements.js
```

The Marp deck is exported to [06_conditional_statements.html](06_conditional_statements.html).
