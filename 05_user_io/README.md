# User Input and Output

This tutorial will introduce terminal output and typed values supplied by a user.

The lesson deck is [05_user_io.md](05_user_io.md), and its examples are in [05_user_io.ts](05_user_io.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/05_user_io/05_user_io.ts && node learn_ts/05_user_io/05_user_io.js
```

The Marp deck is exported to [05_user_io.html](05_user_io.html).
