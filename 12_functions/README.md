# Functions

This tutorial will introduce reusable behavior, parameters, and return types.

The lesson deck is [12_functions.md](12_functions.md), and its examples are in [12_functions.ts](12_functions.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/12_functions/12_functions.ts && node learn_ts/12_functions/12_functions.js
```

The Marp deck is exported to [12_functions.html](12_functions.html).
