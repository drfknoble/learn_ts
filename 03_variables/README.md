# Variables

This tutorial will introduce variable declarations and basic TypeScript types.

The lesson deck is [03_variables.md](03_variables.md), and its examples are in [03_variables.ts](03_variables.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/03_variables/03_variables.ts && node learn_ts/03_variables/03_variables.js
```

The Marp deck is exported to [03_variables.html](03_variables.html).
