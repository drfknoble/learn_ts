# Installation

This tutorial will explain how to install Node.js and the TypeScript compiler.

The lesson deck is [01_installation.md](01_installation.md), and its examples are in [01_installation.ts](01_installation.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/01_installation/01_installation.ts && node learn_ts/01_installation/01_installation.js
```

The Marp deck is exported to [01_installation.html](01_installation.html).
