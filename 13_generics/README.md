# Generics

This tutorial will introduce generic functions, constraints, interfaces, and classes.

The lesson deck is [13_generics.md](13_generics.md), and its examples are in [13_generics.ts](13_generics.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/13_generics/13_generics.ts && node learn_ts/13_generics/13_generics.js
```

The Marp deck is exported to [13_generics.html](13_generics.html).
