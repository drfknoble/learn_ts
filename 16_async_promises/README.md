# Async and Promises

This tutorial will introduce `Promise`, `async`/`await`, error handling, and running tasks in parallel.

The lesson deck is [16_async_promises.md](16_async_promises.md), and its examples are in [16_async_promises.ts](16_async_promises.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/16_async_promises/16_async_promises.ts && node learn_ts/16_async_promises/16_async_promises.js
```

The Marp deck is exported to [16_async_promises.html](16_async_promises.html).
