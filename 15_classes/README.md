# Classes

This tutorial will introduce classes, constructors, and encapsulated behavior.

The lesson deck is [15_classes.md](15_classes.md), and its examples are in [15_classes.ts](15_classes.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/15_classes/15_classes.ts && node learn_ts/15_classes/15_classes.js
```

The Marp deck is exported to [15_classes.html](15_classes.html).
