# Null and Undefined

This tutorial will introduce `null`, `undefined`, optional properties, optional chaining, and nullish coalescing.

The lesson deck is [04_null_undefined.md](04_null_undefined.md), and its examples are in [04_null_undefined.ts](04_null_undefined.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/04_null_undefined/04_null_undefined.ts && node learn_ts/04_null_undefined/04_null_undefined.js
```

The Marp deck is exported to [04_null_undefined.html](04_null_undefined.html).
