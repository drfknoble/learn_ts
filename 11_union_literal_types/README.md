# Union and Literal Types

This tutorial will introduce union types, literal types, narrowing, and intersection types.

The lesson deck is [11_union_literal_types.md](11_union_literal_types.md), and its examples are in [11_union_literal_types.ts](11_union_literal_types.ts).

## Run the Example

From the parent directory of `learn_ts`, run:

```bash
tsc learn_ts/11_union_literal_types/11_union_literal_types.ts && node learn_ts/11_union_literal_types/11_union_literal_types.js
```

The Marp deck is exported to [11_union_literal_types.html](11_union_literal_types.html).
